# Chinese Hackers Use AI Security Tool to Target ConnectWise and Global Cloud Systems

A Chinese-linked hacking group utilized AI-driven security assessment tools to carry out cyberattacks against IT provider ConnectWise and hundreds of global organizations. Microsoft reported that while many attacks failed, threat actors successfully gained high-level access to several targets' cloud systems.
