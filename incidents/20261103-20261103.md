# AI Manga Translation Tool Inserts Safety Refusal Message into Published Comic Page

An automated AI translation tool misconstrued benign manga context as policy-violating content and generated a system refusal message instead of a translation. The uploader published the raw AI output without human moderation, resulting in the error message appearing directly within the manga's speech bubble.
