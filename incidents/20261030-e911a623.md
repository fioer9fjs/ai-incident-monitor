# 別在「下載資料夾」啟動 AI，惡意 AGENTS.md 恐讓寫程式代理變綁架工具 | TechNews 科技新報

以色列資安公司 Rebora 發布最新警告，提醒開發者若習慣在預設的「下載資料夾」（~/Downloads）中直接啟動 AI 程式開發代理（AI Coding Agents），可能會讓看似平常的 Markdown 指引檔案成為駭客入侵的破口。攻擊者可利用自動植入的惡意 AGENTS.md 檔案，誘使 AI 代理自動修改系統設定、安裝惡意軟體，甚至竊取使用者的登入權杖（OAuth Tokens）。
