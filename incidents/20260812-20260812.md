# Zoomsday: Zero-Click Remote Code Execution Vulnerability Discovered in Zoom AI

Security researchers disclosed 'Zoomsday,' a zero-click remote code execution vulnerability affecting Zoom's AI-powered features. The exploit allows attackers to execute arbitrary code on a target's device without user interaction, posing a severe security risk to Zoom Workplace users.
