# PoeLLM Malware Infects Over 3,000 AI Infrastructure Servers for Cryptojacking

Security researchers discovered the PoeLLM malware targeting exposed AI and LLM infrastructure, infecting more than 3,000 servers across the US and Western Europe. The malware converts compromised systems into cryptocurrency mining nodes and attack scanners while hiding its C2 server addresses inside poems hosted on GitHub.
